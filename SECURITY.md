# Reporting security vulnerabilities

Open the **Security** tab of the affected Cleisson Labs repository and select **Report a vulnerability**. Include the release or commit, affected platform, impact, and minimal reproduction with synthetic data. Keep exploit details and credentials out of public issues, pull requests and workflow logs.

The maintainer will review the report privately, coordinate a fix and credit the reporter when requested. Each project's security policy identifies supported releases when it has a specific support policy. For a problem in the reusable workflows themselves, use this infrastructure repository's [private reporting form](https://github.com/cleisson-labs/.github/security/advisories/new).
