# Cleisson Labs

Open-source tools for developers who work with images, coding agents, and the command line.

| Project | What it does |
| --- | --- |
| [DevImg](https://github.com/cleisson-labs/devimg) | Builds and checks reproducible image assets for frontend projects. |
| [File System MCP](https://github.com/cleisson-labs/file-system-mcp) | Gives MCP clients file tools scoped to a workspace. |
| [Teams MCP](https://github.com/cleisson-labs/teams-mcp) | Gives coding agents read-only access to Microsoft Teams. |
| [Kitmux](https://github.com/cleisson-labs/kitmux) | Manages MCP servers, skills, and subagents across coding agents. |
| [CLI Tools](https://github.com/cleisson-labs/cli_tools) | Command-line utilities for image processing, HTTP requests, and other everyday tasks. |
| [Jira → Toggl Quick Start](https://github.com/cleisson-labs/jira-toggl-quickstart) | Starts and stops Toggl Track timers from Jira issues in Chrome. |

Find more of Cleisson's work at [cleisson.com](https://cleisson.com).
